# 🛒 Supermarket Billing System

A modern JavaFX-based supermarket billing system with separate Admin and Customer interfaces.

---

# ✨ Features

## 🔐 Login System
- Admin Login
- Customer Login
- Role-based navigation

---

## 👨‍💼 Admin Panel
- Dashboard UI
- Revenue Cards
- Orders Analytics
- Inventory Management
- Add Products Dynamically
- Stock Display

---

## 🛍️ Customer Interface
- Product Shopping UI
- Dynamic Cart System
- Quantity Increment & Decrement
- Auto Total Calculation
- Product Images
- Payment Workflow

---

## 💳 Payment Module
- Payment Summary
- GST Calculation
- Total Amount Calculation

---

## 🧾 Receipt Generation
- Receipt Page
- Purchased Items Summary
- Date & Time
- Total Bill

---

# 🛠️ Tech Stack

- Java
- JavaFX
- CSS
- FXML
- VS Code
